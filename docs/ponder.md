# Ponder tutorials

Install **PonderJS 1.21.1-2.4.0** on your client to enable the optional tutorials. The mod works without PonderJS. The scenes come with Fly by Instruments; no script installation is needed.

Hover a supported item in your inventory and hold the **Ponder** key shown by Create (W by default). Select a scene and use Ponder’s pause, replay and chapter controls. Change Minecraft’s language to switch between English and Brazilian Portuguese. Wiring View instructions show your configured key.

## Tutorials

| Scene | Open from |
| --- | --- |
| Measuring height above terrain | Radar Altimeter |
| Detecting obstacles ahead | Terrain Scanner |
| Separating front, left and right | Advanced Terrain Scanner |
| Bringing readings into the cockpit | Any of the three sensors |
| Installing the avionics network | Avionics Wire, Wire Connector, Wire Support |
| Inspecting and repairing wires | Avionics Wire, Wire Connector, Wire Support |
| Building your first GPWS protection | Avionics Computer, Modular Table |
| Expanding protection with scanners | Avionics Computer, either Terrain Scanner |
| Building a modular cockpit panel | Modular Table, lamps, buzzer, FMS |
| Understanding and silencing alerts | Avionics Computer, lamps, buzzer |
| Navigating with waypoints | FMS, FMS Compass |

For a first cockpit, watch the wire installation scene, then **Building your first GPWS protection**. Add the scanner expansion and panel tutorials as your cockpit grows. For navigation, follow the FMS tutorial through linking the compass and inserting it into an Aeronautics Navigation Table.

The dioramas illustrate sensor and alert behaviour with controlled demonstrations. They do not pilot a ship. CC:Tweaked and the creative-only Network Bridge are covered by the written guides.

## If the Ponder prompt is missing

Check that PonderJS is installed for Minecraft 1.21.1 / NeoForge, restart the client, and hover one of the listed items. Create’s Controls settings determine the Ponder key.

# Tutoriais Ponder

Instale **PonderJS 1.21.1-2.4.0** no cliente para habilitar os tutoriais opcionais. O mod funciona sem PonderJS. As cenas acompanham Fly by Instruments; não é preciso instalar scripts.

Passe o mouse sobre um item compatível no inventário e segure a tecla **Ponder** indicada pelo Create (W por padrão). Escolha uma cena e use os controles de pausa, repetição e capítulos. Mude o idioma do Minecraft para alternar entre inglês e português brasileiro. As instruções de Wiring View exibem a tecla configurada.

## Tutoriais

| Cena | Abrir pelo item |
| --- | --- |
| Medindo a altura sobre o terreno | Radar Altimeter |
| Detectando obstáculos à frente | Terrain Scanner |
| Separando frente, esquerda e direita | Advanced Terrain Scanner |
| Levando leituras até o cockpit | Qualquer um dos três sensores |
| Instalando a rede de aviônicos | Avionics Wire, Wire Connector, Wire Support |
| Inspecionando e corrigindo fios | Avionics Wire, Wire Connector, Wire Support |
| Montando sua primeira proteção GPWS | Avionics Computer, Modular Table |
| Ampliando a proteção com scanners | Avionics Computer, qualquer Terrain Scanner |
| Construindo um painel modular | Modular Table, lâmpadas, buzzer, FMS |
| Entendendo e silenciando alertas | Avionics Computer, lâmpadas, buzzer |
| Navegando com waypoints | FMS, FMS Compass |

Para a primeira cabine, assista à instalação dos fios e depois a **Montando sua primeira proteção GPWS**. Acrescente os tutoriais de scanners e painel conforme a cabine crescer. Para navegação, siga o tutorial do FMS até vincular a bússola e inseri-la numa Navigation Table do Aeronautics.

Os dioramas ilustram sensores e alertas com demonstrações controladas. Eles não pilotam uma aeronave. CC:Tweaked e a Network Bridge exclusiva do criativo são explicados nos guias escritos.

## Se a indicação de Ponder não aparecer

Confira se o PonderJS está instalado para Minecraft 1.21.1 / NeoForge, reinicie o cliente e passe o mouse sobre um dos itens da lista. A configuração dos Controles do Create determina a tecla de Ponder.
